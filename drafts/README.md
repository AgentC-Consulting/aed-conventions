# Drafts — not canon, not published

The two dev.to posts in this folder were written against **v1.0.0**, when the
public repository contained only the six edit-level style rules. They frame AED
as a six-rule style guide.

As of `v1.1.0-rc.1` that framing is wrong. The canon leads with the
token-window rationale, the naming doctrine, process managers, and feature
stories; edit-level style is chapter 05, not the headline. See the
[reading order](../README.md#reading-order).

These drafts are kept here because they are real drafts with a real history,
not because they are accurate. They have never been published to dev.to, and
they await the author's own voice review before anything is scheduled. Do not
cite them, and do not treat them as a summary of AED.

If you want a short introduction, read
[01_why_models_need_this.md](../01_why_models_need_this.md) and then
[quick_reference.md](../quick_reference.md).
